# MAGeCK2 Maintainers

This file lists the current maintainers of MAGeCK2. Maintainers are responsible for reviewing and
merging contributions, managing releases, triaging issues, supporting the community, and stewarding
the [roadmap](ROADMAP.md). See [GOVERNANCE.md](GOVERNANCE.md) for the roles and decision-making
process.

## Becoming a maintainer

The maintainer team grows as contributors demonstrate sustained, high-quality involvement. See
[GOVERNANCE.md](GOVERNANCE.md#becoming-a-maintainer) for details.
